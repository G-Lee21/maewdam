# แมวดำมาเย้ย · MaewDam

**ไทย** — แอป Android โหลดวิดีโอ เพลง และรูป จากลิงก์ที่คุณเปิดดูได้ ค้นหาคลิป แชร์ลิงก์จากแอปอื่นแล้วกด "โหลดด่วน" ไฟล์เก็บในแฟ้ม Download/MaewDam ไม่มีโฆษณา ไม่ต้องสมัครสมาชิก

วิธีลง: โหลดไฟล์ `.apk` จากหน้า [Releases](https://github.com/G-Lee21/maewdam/releases) → แตะไฟล์ในมือถือ → ถ้าขึ้นว่าไม่อนุญาต ให้กด "การตั้งค่า" แล้วเปิด "อนุญาตจากแหล่งนี้" → ติดตั้ง (Android 7 ขึ้นไป มือถือ 64 บิต)

**English** — An Android app that saves videos, music and pictures from links you can open. Search for clips, or share a link from another app and tap "Quick download". Files go to Download/MaewDam. No ads, no account.

How to install: download the `.apk` from [Releases](https://github.com/G-Lee21/maewdam/releases) → tap it on your phone → if Android blocks it, tap "Settings" and turn on "Allow from this source" → Install (Android 7+, 64-bit phones).

Please download only content you have the right to save.
